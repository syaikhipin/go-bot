# 移动端设计

[Manix Agent App](https://dribbble.com/shots/27236956-AI-Assistant-Multimodal-Agent-App) 提供页面布局参考，[Taste Skill](https://github.com/leonxlnx/taste-skill) 提供界面设计参考。产品采用近白底色、柔和薄荷色和少量淡紫色。浮动导航按「任务、会话、我的」排列。会话里只有用户消息带气泡。助手的文本、图片、文件和工具调用按顺序展开，连续图片采用正方形缩略图，连续工具调用折叠成一组。

| 会话与模型 | 附件库 | 任务与设置 |
| --- | --- | --- |
| [会话原型](../assets/prototypes/chat.webp) | [附件原型](../assets/prototypes/attachments.webp) | [任务与设置原型](../assets/prototypes/tasks-and-me.webp) |

ImageGen 原型覆盖了连接页、发送前后的会话元素、模型切换、附件菜单、设备本地图片与文件、任务列表和详情、账号设置。实现阶段将会话放在导航中央、降低紫色饱和度，并统一弹层的外侧收起交互。停止运行的操作在「我的」中使用 `Stop Host`，头像入口提供图库和相机。

## 页面与数据

| 页面 | 交互 | 数据来源 |
| --- | --- | --- |
| 连接 | 输入 HTTP(S) 地址和账号，连接已有账号或创建账号 | Controller 管理账号和 Host，手机只记住地址和账号 |
| 会话 | 侧边抽屉切换会话。输入框暂存附件、切换模型和发送消息。等待首个回复时显示等待状态，收到内容后显示生成状态 | 先读会话历史，再通过 SSE 接收进度。使用 Web 共用的会话事件投影渲染内容块 |
| 任务 | 列表按待执行和已完成分为两个标签，每个标签按日期分组。右上角加号创建任务；点击卡片从底部打开详情，查看下次运行、投递目标和最近一次投递 | 任务规则、终态与投递记录由当前账号的 Host 管理 |
| 我的 | 管理三类供应商配置。点击头像打开图库或相机。用 Stop Host 停止运行 | 供应商设置由 Controller 保存，头像只写入手机并以账号名为索引 |

模型、附件、提问和文件预览都使用同一套底部弹层。点外侧收起当前弹层。收起提问后，输入框上方仍可重新打开。相册导入的图片和文件选择器导入的文档分别进入设备本地的图库和文件库，用户在草稿确认发送时才把选中的附件交给 Host。

## 界面细节

全局以近白为底，左上角有青色晕染，右下角有淡紫色。标题、正文与辅助信息分别使用清晰的字重，任务列表、设置和弹层对齐同一内容边界。导航及文件系统入口使用透明线框图标。助手头像和生成状态在一行，正文另起一行贴左。图片库、文件库、任务详情和设置从底部滑入，附件快捷菜单和提问在会话上方悬浮。图标清单见 [图标来源](icons.md)。
