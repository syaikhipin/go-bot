# 移动端图标

| 位置 | 需要的图标 | 来源 |
| --- | --- | --- |
| 浮动导航 | 任务、会话、我的 | Lucide |
| 会话 | 侧栏、文件系统、新会话、模型下拉、附加、发送、停止、提问、引导、移除、下载、关闭 | Lucide |
| 工具和任务 | 工具组、成功、失败、日历、时钟、定时规则、投递目标、展开 | Lucide |
| 附件面板 | 相册、图片库、文件库、导入、选中、文件夹、返回上级、刷新 | Lucide |
| 文件类型 | PDF、Word、PowerPoint、Excel、Markdown | VS Code Icons |
| 其他文件 | 文本、图片、代码、压缩包、音频、视频、通用文件 | Lucide 轮廓与格式专用底色 |
| 设置 | 模型、搜索、生图、语言、服务器、相机、图库、关机 | Lucide |

[Lucide](https://github.com/lucide-icons/lucide) 提供统一线宽和覆盖面广的原生交互图标。[VS Code Icons](https://github.com/vscode-icons/vscode-icons) 用于需要凭颜色与形状快速辨认的文件格式。精选文件图标固定在 [上游版本](https://github.com/vscode-icons/vscode-icons/tree/814aab8318900f47efeae6f1c4691494ae764199/icons)，从 App 本地资源读取，许可证随资源保存。
