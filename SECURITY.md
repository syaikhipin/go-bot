# Security policy

Please report suspected vulnerabilities privately. We triage reports against the
default branch and the latest release, when one is available.

On GitHub, open this repository's **Security → Advisories** page and choose
**Report a vulnerability**. If that option is unavailable, open a public issue
asking for a private contact and keep all vulnerability details out of the issue.
[GitHub's private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the affected commit or release, the Docker or ECI deployment mode, the
conditions needed to reproduce the issue, the potential impact, and any relevant
logs with sensitive data removed. Keep API keys, cloud credentials, and personal
data out of the report. Please coordinate disclosure with the maintainers.
