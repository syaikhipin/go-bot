# Schedule 还原与移动端任务管理

以 [DeepSeek Harness 39163dd 的 Schedule 规范](https://github.com/deepseek-ai/deepseek-harness/blob/39163dd30f703a79079e2d2446545cff3c453738/docs/subsystems/schedule.md) 为基线。Schedule 在 Host 内按规则把任务指令写入会话收件箱。收件箱确认写入时生成投递回执，Agent 随后在会话里执行指令，因此「已投递」「任务已结束」「Agent 已完成」代表三个不同的时刻。

## Host 和接口

- 定时投递、立即运行和任务写入使用同一把锁。既有或复用会话的任务等上次投递对应的 Agent 空闲再接纳下一次，停机或等待期间只补最近一次。每个任务至少间隔 60 秒，`new` 目标可使用更长的间隔。恢复时用上次回执定位会话收件箱中的原消息。
- 一次性任务或有限规则耗尽后保留 `ended`。立即运行只新增一条投递，不推进计划时间。列表和详情以任务为单位，编辑比较 `updatedAt`，投递同样推进该字段。清理只删除 `ended` 任务及其历史。
- Go 模型工具采用 `schedule_create/list/view/edit`。模型使用 RRULE，移动端通过共享管理接口提交带类型的时间规则。任务变更异步注入已加载的关联 Agent，在下一步生效。
- 定时规则、RRULE 的 `TZID` 和消息上报的客户端时区共用 Go 时区解析。输入别名按 IANA 映射到主名称，定时规则仍按当地时间和夏令时计算。
- `new_once` 与 `new` 在首次创建前持久化会话 ID。模型创建任务时捕获当前会话的工作目录，新会话使用任务标题，逐次新建时附上规则时区中的创建时间。移动端创建新会话目标时可以选择 Host 上已有的目录，省略时使用 Host 默认工作区。Go 的 Agent 运行组合固定，已记录的 preset 作为会话元数据保留。

## 会话、工作区与归档

上游 `session.create` 接受工作区 ID 或工作目录，省略时用 Host 默认目录。会话的 v4 头部保存起始 `cwd`，目录内的文件和会话日志各自持久化。多个会话可以指向同一个目录。

Go 手动新建聊天继续默认创建 `/root/harness/workspaces/<会话 ID>`。会话启动、列表、归档、附件和回放都通过实际日志位置与头部 `cwd` 解析会话的工作目录。查询优先读取默认位置，也能找到共享目录下的会话日志。定时任务捕获或显式选择已有工作区时，在同一个目录启动独立聊天。每轮新开会话时，后续会话仍使用任务保存的目录。

默认归档检查会话运行状态和关联的启用中任务。界面收到活动冲突时给出「停止并归档」确认。确认后写入归档标记、停止会话执行并删除直接指向它的活跃任务。暂停或结束的任务仍可查询，向已归档会话手动投递或恢复任务会报错。归档不会删除历史和工作目录。

## 移动端信息和操作

| 字段 | 含义和位置 |
| --- | --- |
| `record.title`、`record.prompt` | 列表显示标题，详情显示每次投递的指令。 |
| `status`、`record.scheduledAt` | 启用中的任务显示下次计划时间，暂停和结束只显示对应状态。结束说明计划已耗尽。 |
| `record.kind` 与规则字段 | 用一次性、固定间隔、每天、每周或自定义规则解释频率。规则时区和可编辑表达式放入详情或编辑表单。 |
| `target.kind`、`target.sessionId` | 显示投递到既有、新建后复用、每次新建三种方式，提供打开目标会话的入口。未创建时显示待创建。 |
| `executionActive`、`deliveryFloorEndsAt` | 显示排队或运行中的合并状态，并解释立即运行暂不可用的原因。间隔提示不改变任务状态。 |
| `lastDelivery.deliveredAt` | 显示最近一次将指令写入会话的时间。执行结果在会话里查看。 |
| `id`、`messageId`、`involvedSessionIds`、`pendingDelivery`、`updatedAt` | 用于路由、分页、修订比较和恢复，不占据界面。 |

列表分为待执行（`active`、`paused`）和已完成（仅 `ended`），按日期分组。待执行任务按下次计划排序，暂停任务排在末尾；已完成任务最近投递的排在前面。详情保留立即运行、暂停或恢复、编辑和删除；投递历史保留在 Host 接口，移动端只显示最近一次投递。新建与编辑共用表单。删除单个任务和清理已结束任务前确认。
